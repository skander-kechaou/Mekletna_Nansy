# 🍽️ Mekletna – Tunisian Catering Platform

**Mekletna** is a catering website built with core web technologies: **PHP**, **HTML**, **CSS**, and **JavaScript**. The platform lets users explore regional menus, discover chefs, and order homemade dishes from catering providers across Tunisia.

> 🇹🇳 Promoting local gastronomy and regional food artisanship.

---

## 🌟 Features

- 📋 **Browse Menus** — Discover curated menus and detailed food items
- 👨‍🍳 **Chefs by Region** — Explore chefs and dishes from across Tunisia
- 🛒 **Cart System** — Add dishes to your cart and proceed to checkout
- 🌍 **Regional Focus** — Promotes regional gastronomy and local cuisine

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP (no framework)
- **Database**: MySQL
- **Environment**: XAMPP (Apache + MySQL)

---

## 🚀 Getting Started

### 1. Set Up Environment

Install and run **XAMPP**.

- Start **Apache** and **MySQL**
- Place the project folder in `htdocs`

### 2. Configure the Database

- Import the provided `.sql` file into **phpMyAdmin**
- Update any database credentials inside PHP files if needed

### 3. Run the Website

In your browser, open the home file from the htdocs folder
